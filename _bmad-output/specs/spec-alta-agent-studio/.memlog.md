- (note) Audit finding: zero latency or token instrumentation exists — no perf_counter/monotonic timing on any model call, and vapi_adapter.py:200 hardcodes usage to zeros. Nothing can be ranked until this lands.
- (note) Audit finding: structured outputs are ALREADY in use (llm_client.generate_structured uses .beta.chat.completions.parse with a JSON-mode + regex-extract fallback for non-OpenAI endpoints). The residual is modernization (promoted .chat.completions.parse, strict schemas), not adoption.
- (note) Audit finding: build_think_system puts CURRENT DATE/TIME on line 2, ahead of GROUND TRUTH and the slot docs, so a per-turn timestamp invalidates the whole prefix for automatic prefix caching. build_knowledge_system places volatile retrieved_ctx mid-prompt for the same effect.
- (note) Audit finding: the reply path never streams model tokens — runtime.py awaits graph.ainvoke to completion, then sentence-chunks a finished final_response. Sentence chunking covers TTS start, not generation time.
- (note) Audit finding: retrieval is a term-overlap prefix scorer over an in-memory config.DOCS list (config.py ~764-772), with RETRIEVAL_MIN_SCORE defaulting to 0 and an LLM rewrite loop compensating for lexical misses. The RETRIEVER seam exists; no real retriever ships.
- (note) Audit finding: a tool turn costs three serial model calls (intent structured, think structured, enrich structured) plus the tool. That chain, not prompt size, dominates turn latency.
- (decision) Embeddings via the OpenAI-compatible /v1/embeddings surface keep provider-agnostic STRICT intact, so hybrid BM25+dense retrieval is available without binding a vendor SDK; blank key degrades to BM25 so mock mode and the selftest stay deterministic.
- (decision) Recommend AGAINST replacing LangGraph with an agent-loop SDK: it would reintroduce model-driven routing (the measured rejection in ARCHITECTURE.md section 1), and a vendor agent SDK inside a generated agent would violate provider-agnostic STRICT. Thinning the dependency is a separate, low-priority dependency play.
